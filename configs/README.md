# Scripts de configuración

Un archivo `.txt` por equipo con los comandos listos para pegar en la CLI de Packet Tracer.

| Carpeta | Archivos |
| --- | --- |
| `grecia/` | `GRE-RT01.txt`, `GRE-SW01.txt`, `GRE-SW02.txt`, `GRE-SW03.txt` |
| `san-ramon/` | `SR-RT01.txt`, `SR-SW01.txt`, `SR-SW02.txt`, `SR-SW03.txt` |
| `perez-zeledon/` | `PZ-RT01.txt`, `PZ-SW01.txt`, `PZ-SW02.txt`, `PZ-SW03.txt` |

Cada script se arma por bloques comentados con `!` (hostname y hardening, VLANs, trunks, puertos de acceso, SSH…), siguiendo las tablas del README principal. Si se cambia una IP o puerto, se cambia primero en el README.
