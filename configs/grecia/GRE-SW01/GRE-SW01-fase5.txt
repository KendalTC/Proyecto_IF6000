! Bloque ....: Configuracion Fase 5 - Seguridad
! Fase ......: 5
! Que hace ..: 3 usuarios admin, enable secret, banner, consola y VTY con login local, VTY solo SSH v2; shutdown de puertos sin uso (Fa0/23)
! Requiere ..: Fase 1 aplicada; hostname puesto (lo usa la llave RSA)
! Decisiones : D4.1, D4.2, D4.3
! Autor .....: Jose Solorzano (08/11/2026) - formato: Claude/KendalTC (09/11)
! Estado ....: [ ] Pendiente  [x] Aplicado  [x] Probado (Jose)
!------------------------------------------------------------
! VERIFICAR:
!   show ip ssh -> SSH Enabled - version 2.0
!   ssh -l kendal 172.27.86.114 desde GRE-ADM-LT01 -> pide clave (redes), muestra el banner y entra
!   telnet 172.27.86.114 desde GRE-ADM-LT01 -> rechazado
!   show running-config | include username -> exactamente 3 usuarios
!   show interfaces status -> puertos sin uso en "disabled"
! SI FALLA:
!   show ip ssh dice 1.99 -> falta "ip ssh version 2"
!   "% Please define a domain-name first" -> falta ip domain-name
!   SSH rechaza la clave -> revisar username ... secret redes
!   Consola pide usuario: usar kendal / mariangel / sebas, clave redes
!============================================================
enable
configure terminal
!
! --- Base: sin busqueda DNS y dominio (requisito para la llave RSA) ---
no ip domain-lookup
ip domain-name clavitoveloz.com
!
! --- Contrasenas: enable cifrado y cifrado de las que quedan en texto ---
enable secret proyecto
service password-encryption
!
! --- Exactamente 3 administradores (punto 7 del enunciado) ---
username kendal privilege 15 secret redes
username mariangel privilege 15 secret redes
username sebas privilege 15 secret redes
!
! --- Mensaje de bienvenida (punto 4 del enunciado) ---
banner motd "ACCESO RESTRINGIDO, SOLO PERSONAL AUTORIZADO - EL CLAVITO VELOZ"
!
! --- Consola: pide usuario local, no corta lo que se escribe, cierra a los 5 min ---
line console 0
 login local
 logging synchronous
 exec-timeout 5 0
exit
!
! --- Acceso remoto: solo SSH, con usuarios locales ---
line vty 0 15
 login local
 transport input ssh
 exec-timeout 5 0
exit
!
! --- SSH version 2 con llave RSA de 2048 bits ---
! (si Packet Tracer no acepta la linea completa: "crypto key generate rsa" y responder 2048)
crypto key generate rsa general-keys modulus 2048
ip ssh version 2
!
! --- Puertos sin uso apagados (D4.3) ---
interface FastEthernet0/23
 description SIN-USO-PENDIENTE-SHUTDOWN-FASE5
 shutdown
exit
!
end
write memory
